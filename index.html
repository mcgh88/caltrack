// energy

Day colours — green: at or under target · yellow: over target but under TDEE · red: over TDEE · purple: never logged, shown as "!" and counted as TDEE so weight holds flat.

// week

Re-slices the calendar grid and every weekly row, including past weeks. Weekend targets stay on Sat/Sun.

// ranges

Each view shows only its own window. The calendar renders nothing before its start date. Turn on the toggle to lock the graph to the calendar window; turn it off to set the graph separately. Calculations always run across whatever these windows cover.

// data

Import merges day data — imported days overwrite matching dates, your other days are kept.
